# Mis Gastos — app

Interfaz instalable de **Mis Gastos** (tablero de gastos personales).

Este repositorio solo tiene la interfaz: **no contiene datos ni claves**. Los datos viven en un Google Sheet
privado y la app los pide con una clave que se guarda únicamente en el teléfono.

Los archivos se generan con `apps/mis-gastos/web/build.js` del repositorio privado; no editarlos a mano.
